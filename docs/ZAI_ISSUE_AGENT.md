# Заяц — ZAI Agent v2

Единый runtime и формат: [AGENT_RUNTIME.md](AGENT_RUNTIME.md).

Префикс `[ZAI]`, существующий `ZAI_API_KEY`, default `glm-5.3` (также `glm-5.3-flash`).
Финансовый потолок $0.25 и искусственные byte/output caps **отменены владельцем**.
Используются пределы GLM: окно 1M, выход API до 131072 токенов. Контекст, полные файлы,
отчёты и промежуточные результаты не обрезаются. Стоимость — отчёт, не stop gate.

Теперь поддержаны audit-only/edit, новые уроки/билеты/регистрации, схемы/изображения,
glossary/подсказки/теги, тесты и функционал в области координатора. TS resolver
сохранён; selector lesson включает полный контейнер и обязательный контекст.
Последовательные запросы, проверка ошибок и продолжение — через durable checkpoint.
Случайный rerun, устаревший grant и неопределённый повторный расход блокируются.

Секреты не поступают модели/кандидатскому коду. Исполнение проверок — sandbox без
сети и секретов, публикация — только в своей ветке и Draft PR; независимая приёмка
обязательна. Самостоятельный merge/deploy отсутствует. Gemini/ветка Геннадия не менялись.

Новые правила не переигрывают старые v1 оплаченные Issues автоматически; legacy claim
остаётся барьером. Исторические JSON branch/sha/ids задания L3 не мигрируются скрыто:
координатор задаёт новую v2 read-only задачу с нужным контекстом, не меняя чужую ветку.
