# Обязательное правило владельца NetOps

Все объёмные промты и задания для ИИ-агентов публиковать непосредственно в GitHub Issues репозитория staging. В чат владельцу отправлять только ссылку на созданный Issue. Не дублировать текст промта в чате, не требовать повторного напоминания или согласования публикации. Если публикация не удалась, кратко сообщить об этом. Правило действует для всех последующих чатов NetOps. Явное указание владельца от 28.11.2026.
