# Химик — Kimi Agent v2

Единый runtime: [AGENT_RUNTIME.md](AGENT_RUNTIME.md).

Префикс `[KIMI]`, существующий `MOONSHOT_API_KEY`, default model `kimi-k3.1-pro`.
Финансовый потолок $0.25, byte cap, выход 8192 и ограничение edit только литералами
**отменены решением владельца**. Нативный максимум Kimi API — до 1048576 выходных
токенов в пределах окна. Последовательные вызовы разрешены конечным grant координатора,
с полными checkpoint и явным продолжением, без скрытого retry.

Сохранены owner-only, durable claim, учёт расходов/неизвестных попыток, безопасный
sandbox, собственные ветки, обязательные проверки, независимая приёмка, только Draft.
Ручной workflow Kimi Agent также использует общее ядро. Gemini/Геннадий не затронуты.

Эта реализация подготовлена для Draft PR/независимой приёмки. Новых платных вызовов,
merge и deploy при её разработке не выполнялось. Прежние результаты #360/#361 остаются
историческими; изменения урока #361 не сливаются и не переписываются.
