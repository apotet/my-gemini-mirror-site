**Статус решения:** APPROVED. **Статус уровня:** НЕ ACCEPTED, финальные работы ещё открыты.
**Обязательный сопутствующий документ:** [LEARNING_CONTENT_STANDARD.md](LEARNING_CONTENT_STANDARD.md).
**Оперативный реестр:** [ROADMAP.md](ROADMAP.md).

## Цель и критерии качества

Закрыть 164 вопроса уровня «Углублённый» без десятков новых повторных аудитов, но с качеством учебных материалов, близким к отдельно принятому владельцем уроку и тщательно переработанному уроку PoE (`l1-poe-budget`). PoE на момент решения **не прошёл окончательную пользовательскую приёмку**; это ориентир требований, а не формально принятый универсальный эталон.

Критерий не «вопрос имеет ссылку/текст и CI зелёный», а «ученик, прочитав соответствующий режим урока, сможет обоснованно ответить, понять причину и применить знания». Проверять связь: **условие и дистракторы → ключ → «Почему так» → «Простыми словами» → «По делу» → точный раздел урока → реальная практика/кейс, когда подходит**. Проверять контекстные подсказки, корректность терминов, различие стандарта и вендорской реализации. Не создавать фиктивную практику; не добавлять одинаковые тесты и уроки без учебной необходимости. Простой слой не должен тестировать то, чему в нём не учили.

**Приёмка уровня вопросов и разбора ≠ утверждение каждого связанного урока.** Личная приёмка владельца ведётся по каждому уроку отдельно; по семи маршрутам нельзя объявлять все остальные уроки идеальными.

## Утверждённая команда

| Кто | Роль и ограничения |
| --- | --- |
| **ChatGPT** | Ответственный инженер-интегратор: актуализирует GitHub/PR/SHA, объединяет подтверждённые FIX без потери качества и истории попыток, проверяет доказательства, исправляет код, запускает CI/browser и ведёт ROADMAP. Отвечает за конечный результат; не принимает чужие PASS без проверки актуальности. |
| **Gemini («Геннадий»)** | Главный **независимый педагогический и инженерный аудитор**: один содержательный проход семи учебных маршрутов плюс фактически изменённые спорные места по frozen SHA. Доказательные PASS/FIX/REVIEW/UNVERIFIED; только read-only, без изменения кода, merge и deploy. |
| **Grok** | **Арбитр только при технических разногласиях**: RFC, протоколы, команды CLI, неоднозначные инженерные кейсы и ключи. Не полный третий аудит всех 164. |
| **Qwen** | Не входит в обязательную цепочку: три блокирующих замечания его PoE-аудита не подтвердились по исходникам; использовать лишь при предметной необходимости с повторной сверкой. |
| **Владелец** | Просматривает отдельные уроки вручную и принимает их индивидуально. Только он может отдельно разрешить production-деплой. |

Основание выбора Gemini: в независимом аудите PoE он обнаружил два реальных FIX — несогласованную самопроверку режимов и неточное описание DC resistance unbalance. Оба проверены по исходникам и исправлены. Это не означает безусловного доверия будущим замечаниям.

## Четыре этапа вместо бесконечной ревизии

**1. Единый набор исправлений.** 164 вопроса уже внесены в тестовый `main` через merged PR [#264](https://github.com/apotet/my-gemini-mirror-site/pull/264) от 20.11.2026. На момент решения отдельно открыты Draft [#282](https://github.com/apotet/my-gemini-mirror-site/pull/282), [#283](https://github.com/apotet/my-gemini-mirror-site/pull/283), [#289](https://github.com/apotet/my-gemini-mirror-site/pull/289), [#291](https://github.com/apotet/my-gemini-mirror-site/pull/291). Перепроверить их текущее состояние, диффы и зависимости. #282 и #283 конфликтуют/пересекаются по ряду файлов; #289 и #291 — цепочка зависимых изменений. Не сливать механически. Объединить только проверенные исправления в один согласованный финальный вариант и закрепить frozen SHA.

**2. Один полный технический прогон 164 вопросов.** Проверить ключи и варианты, why/plain/pro, точные `lessonId#anchorId` в обоих стилях, словарь, реальные ссылки и стенды, сохранённые попытки включая `tr-03`/`tr-10`, четыре обязательных UI-состояния «урок есть/нет × pro есть/нет», `lint`, `build`, обязательные CI и GATE-01…10, мобильный/десктопный браузер и возврат в каталог. Глобальные fingerprints нужны для выявления изменений, **не** являются доказательством семантического PASS; не обходить их фиктивным rebaseline. Проверка живого сайта после deploy обязательна для утверждения публикации.

**3. Семь глубоких учебных маршрутов.** Отобрать типичные или сложные реальные кейсы по темам **DNS, TCP, NAT, IPv6, STP, QoS и физической инфраструктуре (оптика/L1/PoE)**. Для каждого пройти всю цепочку «вопрос → разбор → урок (простой и инженерный) → подходящая практика», оценить, сможет ли начинающий понять тему, а инженер — проверить механизм, диагноз, ограничения. Выбирать не самые лёгкие ради PASS.

**4. Один независимый аудит Gemini.** Проверить семь маршрутов и **те смысловые поля, которые изменены** при интеграции. Требовать ID/точный раздел/доказательство/приоритет у каждого FIX. ChatGPT независимо воспроизводит и исправляет реальные проблемы; Grok — только на спорные инженерные вопросы. После исправления — адресная повторная проверка затронутого места + обязательные технические регрессии, **не** полный повтор 164 вопросов.

**Правило системного дефекта:** если семь маршрутов выявляют общий изъян (например, одинаковые поверхностные pro-разборы, неработающие подсказки, несогласованные вопросы), найти и исправить весь затронутый класс, а не объявлять остальные 157 идеальными.

## Условия закрытия и запреты

- **STAGING TECHNICALLY READY:** единый проверенный SHA, обязательные CI/GATE/browser, совместимость истории и работающий опубликованный тестовый сайт; ноль нерешённых блокирующих технических дефектов.
- **L2 CONTENT ACCEPTED:** дополнительно независимая предметная оценка Gemini семи маршрутов и изменённых мест; нет подтверждённых нерешённых FIX, все REVIEW рассмотрены и решения доказаны. Не подменять это статусом «все 164 урока лично приняты».
- **LESSON USER ACCEPTED:** только для конкретного урока по явному решению владельца; новые существенные изменения требуют адресной повторной оценки.
- **STOP/BLOCK:** противоречивый ключ, ошибочный механизм, существенный пробел в обучении, критическая сломанная ссылка или история, обязательный CI/browser FAIL/UNVERIFIED, разногласие без разрешения. Релиз нельзя объявлять готовым, если обязательная проверка не выполнена.
- **Никаких десятков новых полных семантических аудитов.** Ранее проведённую работу использовать как контекст и доказательства при совпадении материала/SHA, но старый PASS не переносить на изменённые материалы автоматически.
- **Production `apotet/netops` не трогать** без отдельного явного разрешения владельца. Тестовый репозиторий — `apotet/my-gemini-mirror-site`.
