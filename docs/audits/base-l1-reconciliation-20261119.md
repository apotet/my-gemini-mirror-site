## Ограниченная реализация

- Только `getTestingPool(..., 'beginner')` и `getTestingQuestions(..., 'beginner')` используют `getLearningLevelPool/getLearningLevelQuestions` для **L1**.
- Параллельный `in-depth` остаётся **L2**, legacy `applied` и `mixed` не затрагиваются; их полный переход на уровни — отдельная задача.
- Сохраняется `selectFamilyQuestions`: уникальные ID, разнообразие `family`, минимум одна подходящая фотография при `count >= 2` и её наличии в выбранной теме. Кастомные выборки и «Работа над ошибками» не добираются из посторонних тем.
- Старые `QuizSession` восстанавливаются по ID и запомненному порядку вариантов. Никакой повторной раздачи уже начатых тестов.
- Матрица регрессии: все темы × длина 1/5/10/15/20/30 × повторяемые seed; равенство счётчиков реальному пулу; сохранённые старые попытки, фото/family, mixed/10 и in-depth.
