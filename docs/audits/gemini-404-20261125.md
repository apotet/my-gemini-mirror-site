# Gemini 404 diagnosis (2026-11-25)

## Confirmed evidence

- Smoke Issue #370, run [45548274570](https://github.com/apotet/my-gemini-mirror-site/actions/runs/45548274570): claim and publish worked. The paid step raised `urllib.error.HTTPError: HTTP Error 404: Not Found`.
- Artifact `accounting.json`: `model=gemini-2.5-pro`, `status=error`, `errorType=HTTPError`, `httpStatus=404`. **Response body was not captured** (agent did not read `exc.read()` at the time).
- models.list with the existing key, no generation, run [45548868207](https://github.com/apotet/my-gemini-mirror-site/actions/runs/45548868207): HTTP 200, 50 models. `models/gemini-2.5-pro` is listed and `supportedGenerationMethods` includes `generateContent`. Also listed: `models/gemini-4-hydrogen`.
- Official REST docs for text generation currently document `POST /v1beta/interactions` with body `{model, input}` and response `{status, steps[].content[].text, usage}`. SDK field `output_text` is a client convenience, not a REST field. Source: https://ai.google.dev/api/interactions-api and https://ai.google.dev/gemini-api/docs/text-generation
- The `generateContent` reference page mentions deprecation. Source: https://ai.google.dev/api/generate-content

## Root cause

**Unknown.** Official Interactions overview states that `generateContent` remains fully supported (https://ai.google.dev/gemini-api/docs/interactions). models.list for this key still advertises `generateContent` on `gemini-2.5-pro`. The HTTP 404 body was not captured, so the API reason string is unavailable. Deprecation is not established.

## Model selection

`gemini-4-hydrogen` is selected because:
1. It is in the models.list result for this key and advertises `generateContent`.
2. It is the model used in the current official Interactions API text-generation example.
3. It is not an image/tts/preview-only variant.

This is a selection based on availability + current docs, not a claim that 2.5 Pro is unavailable.

## Change

Agent now calls `POST /v1beta/interactions`, parses only the documented REST text path (`steps` → `model_output` → `content` → `text`), requires `status=completed`, stores `usage`, and saves a sanitized HTTP error body on failure. No paid generation was repeated for this diagnosis.
