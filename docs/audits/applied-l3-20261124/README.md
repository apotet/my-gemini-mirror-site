## Как читать результат

Это полная поимённая **инвентаризация runtime-содержимого**, а не завершённый независимый предметный аудит. Для каждого вопроса записаны все запрошенные критерии, исходные варианты и ключи, тексты обоих режимов, советы, ловушки, урок/anchor, практика, словарные кандидаты и сигналы повторов. Наличие текста не получает PASS автоматически.

- PASS: подтверждённая содержательная проверка всех применимых критериев. Сейчас таких заключений нет.
- FIX: наблюдаемый пробел покрытия (нет индивидуального plain по runtime-флагу, самостоятельного pro, урока/точного раздела либо anchor не найден в обоих режимах). Это не вердикт о технической ошибке ключа.
- REVIEW: есть сигнал повторяемости, требующий предметной оценки, но нет установленного пробела FIX.
- UNVERIFIED: данных для предметного заключения недостаточно. Техническая корректность, соответствие L3, объяснения дистракторов, релевантность уроков/практики и glossary остаются UNVERIFIED по каждому ID, даже при общем FIX.

Итоговые 376 FIX не означают 376 неверных вопросов: каждый имеет хотя бы один пробел покрытия. Показатели пересекаются, складывать их нельзя. `hasIndividualDeep` — признак resolver, а не оценка педагогики. Разные строки plain/pro не доказывают независимость инженерного объяснения. Совпадения советов и ловушек — точные текстовые совпадения, без семантического анализа. Glossary-кандидаты получены поиском подстрок (возможны ложные совпадения), не являются подтверждением tooltip-покрытия. Отдельного поля hashtags в Question нет; UI-метки не проверены. Объяснения неправильных вариантов могут быть встроены в общий текст: отсутствие отдельной структуры не считается доказательством отсутствия разбора.
