## Контекстный якорь при переключении стилей

Shard 1 в последнем Chromium выявил ошибку геометрии после переключения на «Простыми словами» (при старте урока якорь был видим). `LessonView` перепроверяет видимость точного ID после изменений верстки через 120 и 400 мс, не заменяя якорь похожим текстом. В браузерном тесте добавлены ID, ширина, этап и измерения DOM при любой ошибке, чтобы не маскировать дефекты. По состоянию коммита — **требуется повторный Chromium PASS**.
