## Ветки и публикация
- lesson/<id> — отдельная задача урока; level/<level> — отдельная разработка уровня. Общие инфраструктурные исправления — fix/<topic>. Начинать от актуального staging main, синхронизировать перед merge, не включать чужие незавершённые изменения.
- apotet/my-gemini-mirror-site/main — интеграционное зеркало для личной читки владельца. Технически проверенные уроки публикуются здесь ДО личной приёмки. Отдельный preview не обязателен.
- Зелёная плашка урока только по явному решению владельца. Приёмка уровня и урока независимы. Существенные изменения принятого урока требуют адресной повторной приёмки.
- apotet/netops — только отдельный GO владельца; l1-poe-injectors-splitters требует отдельного OK. Не переносить зеркало целиком автоматически.

## Независимость задач и защита закрытых уровней
- Не ждать личной читки всех уроков для разработки следующего уровня. Незавершённый PR не блокирует работу над независимым PR. Перед merge сверять общий код, зависимости, актуальный base и CI.
- GATE-06 остаётся fail-closed. Сначала вычислить точные изменённые ID и компонентные дельты; если отпечатки совпали, реестр не менять. Если изменились, проверить только затронутые материалы и зависимости, не повторять аудит 164 вопросов.
- Исторические final-review-1/4 и исходный immutable closeout-acceptance-20261124.json и его byte pin сохранять. Для осознанных изменений нужна отдельная версионированная append-only цепочка приёмки: ID, предыдущий и новый SHA256, причина, evidence, основание и явное разрешение владельца на адресную дельту. Зелёный CI сам по себе не разрешает rebaseline.
- До реализации и негативных тестов механизма дельт действующий guard не ослаблять. PR с изменившимися хешами остаётся BLOCK до доказательной адресной приёмки. Независимые PR с неизменными хешами продолжают работу.
- Проверять test:in-depth, test:in-depth-history, строгий fingerprint (без --report-only), lint/build и применимые browser/lesson тесты. Не объявлять PASS по skipped/queued. После merge проверять фактический deploy зеркала.
- ChatGPT — интегратор, Gemini — независимый предметный аудит по необходимости, Codex — объёмная разработка, Grok — технический арбитраж. ROADMAP хранит текущие решения и ссылки на доказательства.
