Последовательные запросы сохраняют полный диалог, reasoning, исходные ответы,
файлы и usage в durable Git ledger; крупные SSE хранятся частями без усечения.
Конечный grant числа вызовов защищает от циклов; продолжение требует владельца,
точного checkpoint и нового grant. Неопределённый результат транспорта не
повторяется автоматически: требуется явное подтверждение возможной оплаты.
Расходы показываются точной суммой только при достаточном usage, иначе диапазоном
или как неизвестные. Денежного потолка нет; сложность задания определяет координатор.

Разрешены код, новые уроки, регистрация связей, билеты, изображения (native image
context при поддержке модели; запись бинарных файлов), глоссарий и тесты в явно
заданных путях. Модель не получает секреты или host shell. Проверки выполняются
в отдельном контейнере без credentials, без сети после установки зависимостей,
с обязательными typecheck/build/questions. Только собственные рабочие ветки и
Draft PR после проверок; независимая приёмка обязательна, merge/deploy отсутствуют.
