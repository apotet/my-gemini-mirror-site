# Observatory Switch Connection Check

This note outlines the steps to verify the connection between imaginary switches **A** and **B** at the small observatory.

## Procedure

1. Confirm both **Switch A** and **Switch B** are in their default resting positions.
2. Toggle **Switch A** and verify that **Switch B** registers the signal change.
3. Return **Switch A** to its original state and confirm **Switch B** follows.
4. Log the connection status in the observatory maintenance sheet.
