# Разбор #486 — gen-bc-26-1

**Простыми словами.** У `/26` в каждой подсети 64 адреса. Для шлюза `192.168.60.190` это `192.168.60.128/26`: адрес сети `.128`, broadcast `.191`, адреса хостов `.129–.190`. Поэтому хост `.130` и шлюз `.190` находятся в одной подсети, а `.62`, `.126` и `.194` — вне неё. Правильный ключ — `[0]`.

**По делу.** Маска `/26` (`255.255.255.192`) задаёт границы `.0–.63`, `.64–.127`, `.128–.191`, `.192–.255`. Хост `.130` при маске `/26` считает шлюз `.190` on-link и может отправлять ARP-запрос напрямую, без промежуточного маршрутизатора. Остальные адреса относятся к другим подсетям. Совпадение по маске само по себе не гарантирует достижимость шлюза: нужны исправный L2-путь, совместимый VLAN, правильная настройка интерфейсов и ответ шлюза на ARP/IP.
